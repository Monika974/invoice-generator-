# Web Invoice Generator (Flask)

A simple web-based invoice generator built using Flask and Python.  
Users can enter customer details, add invoice items, calculate GST, and generate a downloadable DOCX invoice.

## Features
- Web-based UI using Flask
- Dynamic invoice item management
- Automatic subtotal and GST calculation
- DOCX invoice generation using Word templates
- Clean and simple interface

## Tech Stack
- Python
- Flask
- docxtpl
- HTML/CSS
